## Conflict handling

- When the 2027 workbook contradicts the original rulebook, the workbook wins.
- Do not merge contradictory values into a hybrid rule.
- Preserve the superseded value only as provenance when an explanation is useful.
- An internally inconsistent workbook entry remains authoritative as the proposed value but must be labeled `Needs validation`; it must not be silently corrected.
- Workbook gaps do not erase rules found only in the original rulebook.
- Repeated rules on the LT and ET workbook sheets are one logical rule and must not produce duplicate meetings.
- The user explicitly approved using the workbook's February/May/August/November Operations cadence, retaining the PDF's closure, and flagging contradictory workbook dates rather than guessing corrections.
